# Caixa de Vendas LV Tech

Sistema de caixa feito em JavaScript.

## O que faz
- Calcula o total da venda (preço × quantidade)
- Aplica 10% de desconto para cliente fiel com total acima de R$ 300
- Muda o status de "pendente" para "pago"

## Conceitos usados
const, let, if, operadores lógicos (&&) e console.log

## Como rodar
node caixa-vendas.js
